# Destop pet - TInu the syrian hamster
This is a desktop pet which i made for embassy.hackclub.com using the guide from playground.hackclub.com. This is my first godot project. Built using godot. Tinu is a hamster pet which runs in our pc screen and bounces of random edges. He was built for windows operating system. check him out in [itch](https://sasukeop108.itch.io/hamster-pet).

## Features
- **Movable** :Roams in your screen
  
- **Bouncable** : Bounces of at random place
  
- **Draggable**: It is draggable across the screen

- **instagram** : Opens instagram when we run it

## Built with/ Tools used
- Godot engine
- GD script for programming
- Playground guide(helped to learn godot)
- Itch io to publish and get hamster sprite
- Github to offer all files
